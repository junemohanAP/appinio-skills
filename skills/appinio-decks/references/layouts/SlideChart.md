# SlideChart

Chart slide: two-line insight title, chart on a Grey 10 panel, n in the footer.

Use for every data result.

**Provide:** the finding as a title (max two lines), the data, one optional callout, and the base for the footer.

- Title `slide-title` (Bold 45px). The callout pairs one icon from **Icons Blue** (75px) with Inter Medium 24px text.
- The chart sits on a `grey-10` (#F7F7F7) panel. Single series bars are `chart-1` Data Blue (#779DFF); multi-series use the categorical palette `chart-1` … `chart-20` strictly in order and `chart-other` last; gender uses the gender palette (Total `gender-total`, Female `gender-female`, Male `gender-male`, Non-binary `gender-nonbinary`).
- Value labels above the bars and category labels below, Inter Regular 24px, ink. No gridlines, 3D or shadows.
- Base and source as the footer note under the divider (x 67, y 914, 24px, grey-500).
- More than one series: see `SlideSplitChart` (legend, significance letters, split colours). Profiles and other line charts: see `SlideProfileChart`.
