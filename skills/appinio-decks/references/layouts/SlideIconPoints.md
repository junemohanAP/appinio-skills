# SlideIconPoints

Three or four ideas, each with an icon from the official Blue library.

Use for 2–4 parallel points: benefits, method steps, recommendations.

**Provide:** per point an icon name from **Icons Blue**, a headline (max ~4 words) and one or two sentences.

- Icons come ONLY from the Icons Blue (or Icons Grey) group: the SVG already contains its Blue 10 disc. Show it at 96px. If no icon fits, leave icons out for all points.
- Each point is a Grey 10 card (radius 16, padding 40) that fills the height down to the footer; headline Inter Bold 35px, text Regular 24px.
