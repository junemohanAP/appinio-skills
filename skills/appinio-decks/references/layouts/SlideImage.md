# SlideImage

Text left, photo bleeding off the right half.

Use for context, personas and human stories.

**Provide:** title, optional eyebrow, up to ~60 words, one photo from the Imagery group (or a generated one using the brand prompt).

- The photo fills x 993–1920 and the full height (927 × 1080), `object-fit:cover`, square edges. It is listed before the text.
- Text stays in the left column: wrap it in a `width:860px` block. Section padding never exceeds 256px in the Slides format, so never push text into a column with padding. No text over the photo, no overlay.
